# Agent Guidance Tree

You are reading a file under [`docs/agents/`](/docs/agents/) — the
per-session-type playbooks, planning meta-process, and topic-organized
constraint sets that the root [`AGENTS.md`](/AGENTS.md) routes to.

See [`docs/agents/README.md`](./README.md) for the directory map.

The root [`AGENTS.md`](/AGENTS.md) carries the universal rules
(pre-edit gate, scope guardrails, sub-agent delegation, stop-and-
report, anti-patterns, change boundaries) and the session-type
routing table that names which files an agent reads for the work at
hand.
